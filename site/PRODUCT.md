# Torbie website

## Platform and stack
Public web. SvelteKit static, Tailwind v4, npm isolated in site/, GitHub Pages at /torbie. The supplied brief settles the audience, stack and approval to publish.

## Reader and job
Developers running long terminal, agent and server sessions need evidence of what Torbie adds to Tabby before downloading an unsigned Electron app.

## Product truth
Torbie retains Tabby’s plugin API, attributes blocked event loops, restores running pane commands, previews links and inventories and diagnoses builds. Source catalogue and long-form caveats are loaded from docs at build time. Release assets come from the GitHub API with a releases-page fallback. Counts are derived. The Tabby profile remains intact. Windows installs alongside Tabby; Linux deb/rpm declare replacement of tabby-terminal, so use an AppImage or archive to retain that package.

## Content plan
Home: one headline, supporting sentence, download and real app image; then plugin compatibility, recorded diagnostics, pane recovery, link previews, builds and doctor, four visible limits and download. Download: detectable platform/architecture suggestion, all installers and formats, unsigned warnings and profile-copy explanation. Features: searchable, sortable category index with URL state. Detail: source prose, commits, diffstat and complete caveats. 404: clear recovery.

## Success
Every route works at both base paths, themes and required widths; keyboard, axe, performance, root checks and deployed assets verified. Captures use only public demo data. No personal attribution on public surfaces.
