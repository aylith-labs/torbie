# Scenario marks

These marks identify the programs represented by interactive demo fixtures.
They do not imply endorsement or bundled installations.

- Claude and Neovim: https://github.com/simple-icons/simple-icons (CC0).
- Codex: OpenAI mark from https://github.com/lobehub/lobe-icons (MIT).
- Shefrd: existing mark from the Aylith Shefrd repository.
- Polygit: a local `pg` monogram based on the project name; a demo asset, not an official upstream mark. Presented as an Aylith project at the owner's direction.
- btop: https://github.com/aristocratos/btop/blob/main/Img/logo.png (project Apache-2.0).
- Playwright: https://github.com/microsoft/playwright (Apache-2.0), app icon.
- Vite: https://github.com/vitejs/vite (MIT), Vite mark.
